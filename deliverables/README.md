## Ordem recomendada de uso

1. Diretoria: aprovar gasto do serviço de CAPTCHA e justificar o investimento.
2. TI/Backend: provisionar ambiente de produção e validar infraestrutura.
3. Operação: preparar dados reais e validar o fluxo de busca e alertas.
4. Frontend: integrar portal e SSE após o backend estabilizar.
